# Stack

Implementation and practice of the **Stack** data structure using C++.

## 📚 Concepts Covered

- Stack using Array
- Push operation
- Pop operation
- Display operation
- Stack Overflow
- Stack Underflow

## ⚙️ Operations

| Operation | Description | Time Complexity |
|---|---|---|
| Push | Adds an element to the stack | O(1) |
| Pop | Removes the top element | O(1) |
| Display | Displays stack elements | O(n) |

## 🧠 Key Concept

A Stack follows the **LIFO (Last In, First Out)** principle.

Example:

Push: 10 → 20 → 30
