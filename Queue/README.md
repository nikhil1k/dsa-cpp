# Queue

Implementation and practice of the **Queue** data structure using C++.

## 📚 Concepts Covered

- Queue using Array
- Enqueue operation
- Dequeue operation
- Display operation
- Queue Overflow
- Queue Underflow

## ⚙️ Operations

| Operation | Description | Time Complexity |
|---|---|---|
| Enqueue | Adds an element to the rear | O(1) |
| Dequeue | Removes an element from the front | O(1) |
| Display | Displays queue elements | O(n) |

## 🧠 Key Concept

A Queue follows the **FIFO (First In, First Out)** principle.
